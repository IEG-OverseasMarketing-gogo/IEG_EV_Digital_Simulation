Reference Guide — Warehouse Automation (AMR/WMS)

For students who have completed forklift certification and are starting the AMR/WMS module. Reading level: Written to the MSSC CLA-recommended level (9th-grade math, 10th-grade English) so it can sit directly alongside your existing CLA/CLT materials.

1. Four zones of an automated warehouse

Every automated warehouse moves goods through the same four zones, in the same order:

  1. Inbound — Trucks arrive. Workers check items against the order. AMRs carry pallets from here into storage.
  2. Storage / AS-RS — Items sit on racks until needed. AS-RS stands for Automated Storage and Retrieval System — a fixed structure, not a robot. The WMS (see below) tracks exactly which rack and slot holds each item.
  3. Picking / Buffer — AMRs bring items here. A worker checks the item is correct before it moves on.
  4. Outbound — Items are scanned one last time, then loaded onto a conveyor toward the truck.

Key distinction: AS/RS is a storage system. An AMR is a robot that moves. They work together, but they are not the same thing — this comes up again in Section 4.

2. AGV vs. AMR — what's the difference?

AGV AMR
How it moves Follows a fixed path — magnetic tape, a rail, or a wire in the floor Uses sensors and a map to find its own way
Good at Predictable, repeated routes Adjusting when the warehouse layout changes
Downside Expensive to change once installed Needs more computing power on board

Rule of thumb: if the warehouse rearranges its layout often, AMR is the better fit.

3. i-MOBA — IEG's AMR product line

i-MOBA is IEG's own AMR, KC-certified (Korea's national safety and EMC certification — confirms the unit meets a recognized safety standard, similar in purpose to a UL listing in the U.S.).

Type What it does Key specs
Standard Basic point-to-point transport of pallets and boxes Max load: 90 kg · Max speed: 1.35 m/s
Manipulator type Standard unit + a collaborative robot arm (cobot) for picking and loading Cobot: RB5-850 · Payload: 5 kg · Reach: 927.7 mm
Conveyor type ★ Standard unit + a conveyor module on top, for continuous transfer between racks and the picking zone Recommended starting point — closest match to forklift skills (load → move → unload)

Why start with the conveyor type? Forklift work is built around load, move, unload. The conveyor-type i-MOBA does the same basic job — it just does it automatically. The manipulator type asks you to learn a new skill (controlling a robot arm) on top of that, so it comes later.

4. What is a WMS?

WMS = Warehouse Management System. It's the software that keeps a digital record of where every item is, in real time. When an AMR moves a pallet, it reports back to the WMS so the digital record matches the physical world.

Most of the time, this happens automatically and you never think about it. The problem comes when the digital record and the physical world disagree — that's what Session 4 of this module is about.

Reading a WMS alert

A typical alert looks like this:

ALERT #4471
Rack B slot position doesn't match the WMS inventory record
(physical: 12 / system: 15)

This means: someone counted 12 items on the shelf, but the computer thinks there are 15. Before you can fix the number, you have to find the reason for the gap. Common reasons include:

  • A transfer that was never confirmed in the system ("pending")
  • A damaged or misplaced item that was moved by hand, off-system
  • A scanning error at receiving

Rule to remember: always find the reason before you change the number. Editing the inventory count without knowing why the gap exists just hides the problem — it will come back.

5. Glossary

Term Meaning
AMR Autonomous Mobile Robot — moves itself using sensors, not a fixed track
AGV Automated Guided Vehicle — follows a fixed physical path
AS/RS Automated Storage and Retrieval System — a fixed racking structure, not a robot
WMS Warehouse Management System — the software tracking inventory location and movement
Dispatch Sending an AMR a task (for example: "go to Rack B")
Fleet All the AMRs working in one facility, coordinated together
Cobot Collaborative robot — a robot arm designed to work safely alongside people
Cut score The minimum score needed to pass a certification assessment
