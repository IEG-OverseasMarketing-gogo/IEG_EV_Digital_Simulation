Assessment Rubric — Warehouse Automation (AMR/WMS) Module

Instructor-only document. Do not distribute to students. Format modeled on MSSC's own assessment structure (scored checkpoints tied to named work activities, explicit cut scores, immediate diagnostic feedback) so results are reportable in the same terms your school already uses for CLA/CLT.

1. Scoring structure overview

Module MSSC Work Activity Assessed Points available Cut score to pass
Principle — zone identification CLT #1 Product receiving, #2 Product storage, #3 Order processing, #4 Packaging & shipment 20 16 / 20 (80%)
Equipment Operation — AMR dispatch CLT #8 Dispatch and tracking 15 12 / 15 (80%)
Hands-On Scenario — aisle conflict CLA safety principles, extended to automated equipment 10 8 / 10 (80%)
WMS Troubleshooting — inventory mismatch CLT #5 Inventory control, #9 Measurements and metric conversions 25 20 / 25 (80%)
Total 70 56 / 70 (80%)

An 80% cut score matches the pass threshold most MSSC-authorized programs already use for CLA/CLT, so results transfer cleanly into existing school reporting.

2. Module-by-module scoring detail

Principle — zone identification (20 pts)

Criterion Points
Correctly identifies function of Inbound zone 5
Correctly identifies function of Storage/AS-RS zone 5
Correctly identifies function of Picking/Buffer zone 5
Correctly identifies function of Outbound zone 5

Scoring note: currently the demo lets students open zone cards freely with no right/wrong check. To make this scorable, add a short 4-question check ("What happens in this zone?") after the free-exploration phase — multiple choice, one question per zone.

Equipment Operation — AMR dispatch (15 pts)

Criterion Points
Successfully dispatches to all 3 racks 6 (2 each)
Correctly reads WMS sync confirmation after each dispatch 6 (2 each)
Completes all 3 dispatches within the session time window 3

Scoring note: the dispatch log already generates pass/fail-able events ("✓ Arrived… WMS synced"). This can be auto-scored directly from the log without new build work — the LMS dashboard already captures this per station.

Hands-On Scenario — aisle conflict (10 pts)

Criterion Points
Selects the correct response (reassign priority via WMS) 7
Can verbally explain why the other two options are wrong, when asked by instructor 3

Scoring note: this module is currently single-attempt with feedback only. Recommend keeping it single-attempt for the score, since MSSC-style assessments generally don't allow retries mid-assessment — but allow ungraded practice attempts beforehand.

WMS Troubleshooting — inventory mismatch (25 pts)

Criterion Points
Step 1: selects log cross-check over server restart 10
Step 2: selects "confirm transfer + re-sync" over "manually edit count" 10
Completes both steps without instructor intervention 5

Scoring note: this is the highest-weighted module because it maps to two CLT work activities at once (#5 and #9) and is the strongest signal of actual diagnostic competency, not just navigation. Given this module's high first-attempt failure rate (see Instructor Guide), consider allowing one graded retry with a 20% point deduction, rather than a hard single-attempt cutoff — this mirrors how many CTE programs handle a first-pass skills check.

3. Tier badge issuance

Badge Requirement
Blue Forklift certification complete (external — BluWorkz/CLA)
Orange Blue badge held and Principle + Equipment Operation modules both passed (≥80%)
Red Orange badge held and Hands-On Scenario + WMS Troubleshooting modules both passed (≥80%)

A student who passes all four modules but has not completed forklift certification externally holds Orange/Red module credit but does not receive tier badges until Blue is confirmed — this keeps the ladder honest rather than letting the AMR module bypass the entry-level foundation.

4. Reporting to MSSC-aligned programs

Because every scored criterion above ties to a named CLT work activity, a student's results here can be logged as supplementary evidence toward CLT competency in a school's existing MSSC tracking — this doesn't replace the official CLT assessment, but gives instructors documented, activity-level performance data to reference before a student sits the real MSSC exam.

5. What's still needed before this rubric is classroom-ready

  • Build the 4-question zone-identification check for the Principle module (currently free-exploration only)
  • Wire the LMS dashboard to auto-calculate scores from existing log events rather than requiring manual instructor scoring
  • Decide on the WMS Troubleshooting retry policy (single-attempt vs. one graded retry) before finalizing point totals
