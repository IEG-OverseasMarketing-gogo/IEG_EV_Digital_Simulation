Competency Mapping — i-MOBA / WMS Curriculum → MSSC CLA–CLT

Purpose: Show that the IEG AMR/WMS training module isn't built in a vacuum — it's designed against the same national credential framework U.S. CTE schools (including BluWorkz's own partners like TCSG / Savannah Technical College) already teach to.

Framework referenced: Manufacturing Skill Standards Council (MSSC) — Certified Logistics Associate (CLA, foundational) and Certified Logistics Technician (CLT, mid-level). CLA is a prerequisite for CLT. Both are ISO 17024–accredited, nationally validated industry credentials — not an IEG invention.

1. Where each tier sits on the existing MSSC ladder

IEG Tier What it trains MSSC Level Why it fits here
Blue — Forklift (BluWorkz REAL-Forklift, existing) Safe equipment operation, material handling basics CLA (foundational) CLA's own work functions already include "safe material handling and equipment operation" and "safety principles" — this is exactly what REAL-Forklift already certifies

This isn't a new ladder — it's the same CLA→CLT ladder BluWorkz's school partners already report against, with i-MOBA filling the automation-specific rungs that MSSC's generic curriculum doesn't cover equipment-specifically.

3. What's still missing to call this a real curriculum (not just a demo)

This is the honest gap list — what separates "working prototype" from "defensible curriculum package," based on the same structure IEG has used before (Reference Guide + Instructor Guide + Certification Framework, as built for the Hybrid Drivetrain Predictive Maintenance program):

  1. Instructor Guide — lesson-by-lesson teaching notes, timing, common student errors, how to run the branching scenarios as group discussion vs. individual assessment
  2. Reference Guide — the "textbook" companion: AMR/AGV theory, WMS data-flow diagrams, i-MOBA spec sheets, written at a level appropriate for the CLA-recommended 9th-grade reading level
  3. Formal scoring rubric — right now the Hands-On and Troubleshooting modules give feedback but no numeric score; MSSC-style assessment needs pass/fail cut scores per work activity
  4. LMS instructor dashboard — real-time multi-student progress view (IEG already builds this for the Semiconductor VR Station LMS — up to 20 devices monitored live); needed so a BluWorkz-affiliated instructor can run a full classroom, not just a 1:1 demo
  5. Scope & sequence document — total hours, prerequisite order, how this slots before/after REAL-Forklift in a school's existing schedule
